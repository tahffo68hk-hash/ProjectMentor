# SCMU 选课容量监控

这是一个运行在你本人浏览器和登录会话中的 Tampermonkey 用户脚本。它读取“方案内课程”和“推荐课程”两个分类，在右下角列出当前读取到的教学班供你勾选。

脚本每 5 秒刷新一次选课页面。只有已勾选的教学班出现余量，并且找到唯一“选择”按钮时，脚本才点击一次，然后停止并提醒。它不会点击“退选”，不会选择未勾选的教学班。

## 安装

1. 在 Chrome/Edge 安装 Tampermonkey。
2. 打开 Tampermonkey → 新建脚本。
3. 将 `scmu-course-monitor.user.js` 的全部内容粘贴进去并保存。
4. 保持已登录的选课页面打开：
   `https://xk.scmu.edu.cn/xk/plugins/eaxsxk/home?batchid=21c102be-488e-5d38-b6f9-0fee69594229`
5. 页面右下角出现 `SCMU monitor` 面板后，先勾选要监控的教学班，再确认状态为 `Monitoring`。

## 安全行为

- 默认刷新间隔为 5 秒。
- 脚本只读取“方案内课程”和“推荐课程”当前已加载的内容，不自动翻页。
- 发现名额后只尝试一次并停止，避免重复提交。
- 如果学校页面弹出确认框、冲突提示或验证码，脚本不会绕过；请你在浏览器中处理。
- 页面关闭、浏览器休眠、登录过期或校园网断开时，监控会停止或等待页面恢复。

## 停止

点击页面右下角的“暂停”，或在 Tampermonkey 菜单选择“启动/暂停选课监控”。
